Warum Lua sprachunabhängig ist

Numerische RAM IDs

In Emulatoren (BizHawk / mGBA) liest das Lua-Skript das Spiel-RAM direkt aus. Pokémon haben im RAM immer dieselbe numerische ID (1 bis 1025), unabhängig davon, ob das Spiel auf Deutsch, Englisch oder Japanisch läuft!

Einzige Sprachabhängigkeit sind die Speicheradressen (ROM Game Code):

local ROM_MAP = {

  ["BPRD"] = { name = "Feuerrot (DE)", party = 0x02024284 },

  ["BPRE"] = { name = "FireRed (US)", party = 0x02024284 },

  ["BPEE"] = { name = "Emerald (US)", party = 0x020244EC },

  ["BPED"] = { name = "Smaragd (DE)", party = 0x020244EC }

}

Umfassende Dokumentation wird in docs/LUA_TRACKER_GUIDE.md bereitgestellt.
