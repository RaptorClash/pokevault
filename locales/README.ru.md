**PokéVault** — это комплексный, полностью настраиваемый помощник для тренеров Покемонов, коллекционеров и охотников за Shiny, разработанный с использованием Flutter. Независимо от того, планируете ли вы региональный Dex, национальный Dex, Dex форм или Shiny-Dex — PokéVault поможет вам легко отслеживать ваш прогресс и предоставит необходимые инструменты для охоты на Shiny.

## ✨ Основные функции

* **Управление Multi-Dex:** Создавайте столько трекеров, сколько хотите, для разных игр, поколений или собственных задач.
* **Детальное отслеживание форм:** Полная поддержка региональных форм, мегаэволюций, Gigantamax и специальных форм (Pokusan, Vivillon, Unown и т. д.).
* **Просмотр в виде коробки и списка:** Просматривайте своих покемонов в классическом 30-слотовом ПК. Box» или в списке с возможностью поиска с плавным перетаскиванием.
* **Блестящее отслеживание и счетчик охоты:** Отслеживайте обычных и блестящих покемонов отдельно. Встроенный счетчик Shiny Hunt с расчетом вероятности в реальном времени, выбором метода, историей фаз и таймером сеанса с обнаружением паузы AFK.
* **🎖️ Карты Dex Completion:** Создавайте, персонализируйте и экспортируйте сертификаты достижений в высоком разрешении, карты статистики и мозаики покемонов, чтобы поделиться своим прогрессом.
* **Соответствующие шары:** Получайте рекомендации сообщества по лучшим поке Шары (для обычных *и* блестящих вариантов)!
* **📊 Расширенный калькулятор шанса поимки:** Точный расчет вероятности поимки для всех поколений, включая специальную механику из *Pokémon Legends: Arceus* и *Pokémon Legends: Z-A*.
* **🧬 Калькулятор размножения и маршрутов Shiny:** Рассчитывает многоэтапные цепочки размножения (включая Ditto) и детёныши покемонов) и отображает точные вероятности появления целевого потомства.
* **📖 Подробные блестящие руководства по охоте:** Пошаговые инструкции для методов, специфичных для поколения (например, PokéRadar, DexNav, рецепты сэндвичей).
* **🎮 Операции в приложении и ярлыки Обзор:** Собственный экран в настройках с адаптивными к платформе ярлыками и командами мыши и сенсорные жесты.
* **☁️ Cloud Sync и автономный режим:** 100 % автономный режим с надежной локальной базой данных SQLite. Дополнительная синхронизация через ваш личный Google Диск с устойчивостью к слиянию исправлений.
* **Полная персонализация:** Поддерживает темный/светлый режим, а также настраиваемые цвета акцентов и фона.
* **Многоязычный:** Полностью доступен на 13 языках (пользовательский интерфейс через сленг). Кроме того, независимый выбор языка франшизы Pokémon (например, немецкий пользовательский интерфейс с английскими или японскими именами покемонов) на основе 9 официальных языков франшизы в `pokedex.sqlite`.

## 🚀 Первые шаги (Запуск локально)

### Требования
* [Flutter SDK](https://docs.flutter.dev/get-started/install) (рекомендуется актуальная стабильная версия)
* Dart SDK
* Среда разработки, например VS Code или Android Studio

### Установка
1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/RaptorClash/pokevault.git
   ```

2. Перейти в каталог:
   ```bash
   cd pokevault
   ```

3. Скачать зависимости:
   ```bash
   flutter pub get
   ```

4. Загрузка внешних данных и инициализация подмодулей:
   Загрузите самые актуальные репозитории данных и вики, необходимые для базы данных:
   ```bash
   python3 update_data.py
   ```

5. Создание и оптимизация базы данных SQLite:
   *PokéVault требует скомпилированную SQLite-базу данных с информацией о покемонах.* 
   Запустите универсальный скрипт Pipeline, чтобы сгенерировать и оптимизировать `assets/db/pokedex.sqlite` одной командой:
   ```bash
   python3 tool/data_pipeline/run_pipeline.py
   ```
   *(Альтернативно можно использовать `--skip-download`, если у вас уже есть внешние веб-дампы и вы хотите лишь перестроить базу данных).*

6. Запустить приложение:
   ```bash
   flutter run
   ```

## 🤝 Дополнить данные (вклад сообщества)
Тебе не хватает местонахождений или не подходят Matching Balls? Ты можешь дополнить эти данные в JSON-файлах в каталоге `tool/data_pipeline/` (если они есть) или внести вклад напрямую через Issues/Pull Requests.

Если вы хотите внести код, функции или исправления ошибок, пожалуйста, используйте соответствующие шаблоны проблем в папке `.github/ISSUE_TEMPLATE` и откройте пулл-реквест в отдельной ветке для функции.
